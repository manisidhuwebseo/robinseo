Google Removes the Book Actions Data Feed Validation Tool: What Providers Should Check

Google's Search Central documentation update affects a narrow group of book providers using the Book Actions feed process. Here is what changed, what the updated guidance says and what it does not mean for ordinary website SEO.

By Robin SEONovember 20, 2026Google Search & Structured Data NewsUSA & Canada

Google updated its Search Central Book Actions documentation on November 18, 2026. The change is specific: Google removed the section that directed providers to the Data Feed validation tool because that tool has been turned down and is no longer available. The documentation now includes a short section called “Check your feed for common errors.”

This is a narrow documentation and tooling update for book providers working with Google's Book Actions feed process. It is not a general Google ranking update, does not announce a new requirement for ordinary websites and should not be interpreted as a change to all Book structured data.

What Google changed on November 18

Google's Search Central documentation updates page records the November 18 change. It says the previous instruction to test a feed with the Data Feed validation tool was replaced and the link to that tool was removed because the tool is no longer available.

The current Book Actions documentation now tells providers to check common feed errors before hosting the file. The examples specifically call out spelling the @type value correctly and setting @context to https://schema.org for both ReadAction and BorrowAction.

Scope matters: Book Actions is a partner-oriented feature. Google's documentation says participation is limited to book providers with a wide selection of available books who have expressed interest and been onboarded. Most small business websites do not use this feed process.

Who needs to pay attention?

The change is relevant to book retailers, publishers, library systems and technical teams already preparing or maintaining Book Actions feeds for Google. Depending on the provider model, the implementation can involve a Book feed and, for lending providers, a separate Library feed.

If your website simply publishes book descriptions or uses ordinary product markup, do not assume this update changes your standard structured data workflow. First identify whether your organisation is an onboarded Book Actions provider and whether it submits a dedicated feed to Google.

What the updated documentation asks providers to check

The new common-error section is concise. It is not described as a replacement for the retired validation tool with identical functionality. Providers should treat it as a reminder to review the feed specification and test the actual data and destination URLs before submission.

  • Check @type values: confirm that the entity and action types are spelled exactly as required by the specification.
  • Check @context: use the specified Schema.org context for the action entities.
  • Review required properties: confirm that each work and edition has the identifiers and relationships required by Google's feed specification.
  • Use production canonical URLs: Google says feed URLs should be production URLs, not QA or development addresses, and should be canonical.
  • Test destination links manually: Google recommends checking that sample deep links open the page where users can actually buy or borrow the book.

Review the feed structure, not just its syntax

The Book Actions guide describes a feed built around a DataFeed entity. Book and Library information must be structured in the required way, and a provider that supports borrowing may need separate Book and Library feed files. Work and edition records are distinct: a work groups the conceptual book, while an edition represents a specific copy or format.

Identifiers matter. Google's documentation says ISBN-13 is preferred and lists other supported identifiers such as OCLC Number, Library of Congress Control Number and JP e-code. It also warns that ISBN-10 is not accepted as the identifier for this purpose. Teams should verify the current required fields against the official specification rather than copy an old feed template without review.

Do not confuse Book Actions feeds with ordinary structured data testing

A feed validation workflow and a page-level structured data test serve different purposes. The retired Data Feed validation tool was referenced in the Book Actions feed documentation. Its removal does not, by itself, establish that Google's other structured data documentation, testing tools or rich-result eligibility rules have changed.

Likewise, valid structured data does not guarantee a search feature, placement or ranking. Book Actions participation is restricted to eligible providers and involves a review process. Providers should not pay third parties for guaranteed inclusion or assume that adding Book markup to a normal page will create a Book Actions panel.

A practical checklist for technical teams

If your organisation already participates in Book Actions, assign an owner to review the current feed against the latest official documentation. Keep a dated copy of the feed, its schema specification, sample destination URLs and the outcome of manual checks so that changes can be traced.

  1. Confirm that your organisation is an onboarded Book Actions provider.
  2. Identify whether you submit a Book feed, a Library feed or both.
  3. Review entity types, context values, required identifiers and work-edition relationships.
  4. Check that all feed and deep-link URLs use the intended production canonical destinations.
  5. Manually test representative purchase or borrowing links on desktop and mobile.
  6. Keep a record of the submission and any feedback from Google's support team.

For general website owners, the practical lesson is simpler: use current primary documentation for the exact structured-data feature you implement. Do not rely on an old tool link or assume that a validator for one feature checks every feed format.

Frequently asked questions

Did Google remove the Book Actions feature?

No. The November 18 update says the Data Feed validation tool was turned down and removed from the documentation. It does not announce that Book Actions itself has been discontinued.

Is the change relevant to every website using Book schema?

No. It concerns the Book Actions feed workflow. Ordinary websites should review the documentation for the specific structured-data feature they use rather than assume this feed-tool change applies to them.

What replaced the Data Feed validation tool?

Google replaced the old instruction with a “Check your feed for common errors” section. It lists checks for the exact @type spelling and the Schema.org @context. Google does not describe this section as an equivalent automated replacement.

Does the update affect Google rankings?

Google's documentation update describes a retired validation tool and revised instructions. It does not announce a ranking-system change or a new ranking factor.

Where should providers find the current requirements?

Use Google's current Book Actions documentation and the Search Central documentation updates page. Confirm the provider's own onboarding and feed requirements with Google's support process.
